## 7. Traps paid for today

- **Always filter by visibility.** Every view lives in the DOM; `querySelector('main')` returns a
  HIDDEN view's content. Cost me three wrong readings.
- **A red test in a file you do not own may be the shared-tree race.** `web-payload.test.ts` failed
  because another lane wrote to `docs/plays/` between its two reads; 8/8 alone.
- **zsh does not word-split unquoted variables.** A path list in `$paths` went as ONE argument and
  made every case report SKIP — caught only because I ran a control.
- **`rm` is aliased to `rm -i`** and hung a command for 3 minutes. Use `/bin/rm`.
- **Relative imports break in `/tmp`.** Put probes in a `.scratch-*` dir in the repo (vitest
  excludes it).
