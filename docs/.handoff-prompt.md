## Gotchas that cost time — all confirmed today

- **`npm run dev` is BROKEN.** Vercel's Development Command is `npm run dev`, so `vercel dev` refuses as a recursive invocation. To see the UI, serve the build statically: `cd public && python3 -m http.server 8788`. That covers everything except the `/api/deck-url` route. Kill it when done.
- **`public/index.html` and `public/app.js` are BUILD ARTIFACTS.** Edit `web/index.html`, `web/main.ts`, `web/styles.css`. I wasted a cycle editing `public/` and watching the build overwrite it.
- **`test/matcher.test.ts` pins combo quantities.** Editing a `quantity` in `data/combos.json` is a test-visible change. Run `npm test` before committing a data edit and update the numbers while preserving what the test asserts. Do NOT edit `test/fixtures/fury.txt` to make a matcher test pass — `test/deck.test.ts` asserts on that same fixture.
- **Never write the bare word `terminatesIn` into combo prose.** It is the marker for the live-count check (`grep -o terminatesIn` on the deployed bundle) and a note quoting the field name made it read 52 for 51 combos.
- **`data/combos.json` round-trips exactly through `JSON.stringify(doc, null, 2) + "\n"`**, so mutating it with a node script is safe and produces no formatting diff. Ingest/patch scripts live in `.scratch/` (gitignored) as patterns.
- **String `.replace()` in patch scripts fails silently** on curly-vs-straight apostrophes, leaving contradictory old and new text side by side. Assert the match count.
- zsh has noclobber — use `>|` to overwrite. A `#` inside sed replacement text collides with the delimiter; use python for edits mentioning issue numbers.
- Every card text must be verified against `data/corpus_flat.txt` and every rule number against `data/Riftbound-Core-Rules-2026-07-16.txt` (grep, never read whole) before you repeat it.
- Subagents: pass `model: "sonnet"` for web research, `"opus"` for rules walks.
- Reddit answers only to a real browser (Playwright MCP on old.reddit.com). TCGplayer/Cards Realm through `https://r.jina.ai/<url>`. riftbound.gg is Cloudflare-blocked; YouTube captions need the user's own cookies.
