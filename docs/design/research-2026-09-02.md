# Design research — 2026-09-02

Two web-research passes (raw CSS/HTML inspected on the live sites; every value below was
quoted from a stylesheet or page, not inferred) after the first visual pass was rejected.
A third pass on Riot's own visual identity died on a rate limit and was not repeated; the
domain-colour and font findings below cover what it was for.

## 1. Why the first pass failed

The rejected draft (warm near-black, 24px dot grid, mono eyebrow labels with wide tracking,
amber accent, serif italic headline) was, token for token, LOOPLINE's vocabulary:

- LOOPLINE `styles.css?v=81`: `--bg:#090b10; --panel:#0e1118; --line:#252b38; --text:#f5f2ea;
  --muted:#8b93a4; --pink:#ff4f8b; --mint:#60e4bd; --amber:#ffb65c; --violet:#ad7cff;`
- `.map-stage { background-image: radial-gradient(#272d39 1px, transparent 1px); background-size: 23px 23px; }`
- `.noise { opacity:.035 }` (SVG feTurbulence), `.eyebrow { font:700 10px ui-monospace; letter-spacing:.19em }`
- Font: `Inter, "Noto Sans JP", "Yu Gothic UI", sans-serif` everywhere.

The user's follow-up ("fíjate bien la página de referencia") asks for the reference's
*structure and feel*, so the second pass copies LOOPLINE's skeleton and selection model and
drops what house rules forbid (glow filters, noise, emoji result icons, animated dashes,
backdrop blur, box shadows).

## 2. LOOPLINE — structure worth copying (primary: its own CSS/JS)

- Shell: 68px top bar; `grid-template-columns: 310px minmax(0,1fr)`; workspace rows
  `76px minmax(0,1fr) 116px` (head / graph / combo tray); fixed 340px right detail drawer.
- Layered view: three columns with typographic headers
  `.layer-column-label { fill:#657184; font:800 10px ui-monospace; letter-spacing:.18em }`
  and dotted separators `.layer-guide { stroke:#202834; stroke-dasharray:3 9 }`.
- Card nodes are **card images**: `.card-node .frame { fill:#171b23; stroke:#68717d; stroke-width:1.5 }`,
  `.card-image { clip-path: inset(0 round 7px) }`, name plate `.name-bg { fill:rgba(9,11,16,.94); stroke:#363e4a }`,
  `.name { fill:#f0eee8; font:700 11px }`, 18-char truncation with ellipsis.
- Combo ("route") nodes: `.route-shell { fill:#10151c; stroke:var(--route-color); stroke-width:1.2 }`
  with a mono index `.route-index { font:800 8px ui-monospace }`.
- Result nodes: `.layer-result-node rect { fill:#10151c; stroke-width:1.4 }`, label `800 11px`.
- Edges: `.graph-edge { stroke-width:3; opacity:.78 }`; network edges `1.7px` at `.28`, selected `4.5px`.
- Selection: `.isolate-selection .dimmed { opacity:.14; filter:grayscale(1); transition:.18s }`;
  suggested (missing) cards get a dashed accent halo `stroke-dasharray:7 5`.
- Per-outcome categorical palette `['#60e4bd','#ff4f8b','#ffb65c','#ad7cff','#5ec9ff','#ff786f']`
  propagated to routes via `--route-color`.
- Mobile (<900px): columns stack vertically, legend hidden, hover preview becomes a fixed
  bottom sheet `height:min(25dvh,220px)`, `touch-action:none` on the SVG.
- Combo tray chips: `min-width:245px; max-width:285px; border:1px solid #272e3a; background:#10141c; border-radius:5px`.

Domain colours (three independent origins agree: LoL Wiki, riftbound.gg "Domain 101",
Piltover icon sampling): Fury red `#ce212d`, Calm green `#15ac72`, Mind blue `#22799c`,
Body orange `#e4720c`, Chaos purple `#6c4993`, Order yellow `#d0ab01`. Consequence: the
only accent hues that cannot be mistaken for a domain chip are **teal/cyan and pink/magenta**.
Amber sits between Body and Order, which is one reason the first pass read wrong.

Riftbound's typographic signature is Trajan-caps headlines over a neutral sans. "Beaufort for
LOL" is not on Google Fonts; Cinzel is the direct analog, Marcellus a softer one. Use only for
headlines, as Riot does.

## 4. Graph UIs (primary: shipped defaults)

- React Flow light: edges `1px #b1b1b7`, node `1px solid #1a192b` on `#fff`, selected ring `0 0 0 0.5px`.
  Dark: edges `#3e3e3e`, nodes `#1e1e1e` on `#141414`, border `#3c3c3c`.
- tldraw ships every colour as solid/semi pairs per theme; the low-chroma "semi" fill keeps text legible.
- Obsidian: semantic variables resolved / unresolved / focused / line; dashed or fainter = "not yet real".
- nx: solid = static dependency, dashed = implicit; focus mode dims the rest.
- Madge: colour only where it encodes a real property (leaf, cyclic).
- Observable Sankey: nodeWidth 15, padding 10, labels 10px sans anchored by side; never re-sort on selection.

Recurring pattern: semantics live in the stroke, one accent for interaction, selection = dim
the rest and thicken the path, labels 10–13px medium/bold with hard truncation at ~18–22 chars.
